# Security Policy

## Reporting a Vulnerability

Please report security issues privately.

- PGP: available on request

We will acknowledge receipt within 72 hours and provide a timeline for fixes.

## Scope

This policy covers:
- Core chain logic
- Wallet + signing flows
- RPC interfaces
- Explorer UI

Deployment hardening is documented in `docs/security.md`; private producer procedures are consolidated in `docs/operator-guide.md`.

## Out of Scope

- Third-party dependencies
- Self-hosting misconfigurations
